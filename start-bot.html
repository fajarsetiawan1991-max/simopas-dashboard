Panduan Daftar Bot

Untuk menerima pengingat otomatis pajak, STNK, dan service kendaraan dinas via Telegram. Ikuti 4 langkah berikut, hanya 2 menit.

1
Buka Bot SIMOPAS di Telegram
Klik tombol di bawah ini (HARUS sudah install Telegram di HP). Bot akan otomatis terbuka di aplikasi Telegram Anda.

Buka @SimopasBot
2
Klik tombol "START" di bot
Di chat dengan bot, akan muncul tombol biru besar bertuliskan START atau MULAI di bagian bawah. Klik tombol tersebut.

Atau ketik manual: /start lalu kirim.
3
Copy Chat ID dari pesan bot
Bot akan otomatis balas dengan pesan yang berisi Chat ID Anda. Contoh tampilan:
👋 Selamat datang di SIMOPAS Bot!
📋 Chat ID Anda:
123456789
📝 Cara daftar:
1. Copy Chat ID di atas
2. Kirim Chat ID tersebut ke admin SIMOPAS
3. Admin akan input ke sistem
4. Anda akan otomatis dapat pengingat
Tap angka Chat ID untuk auto-copy ke clipboard.
4
Kirim Chat ID ke Admin SIMOPAS
Paste Chat ID yang sudah di-copy, kirim via WhatsApp atau Telegram ke admin SIMOPAS Kanim. Admin akan input Chat ID ini ke sistem, dan Anda otomatis akan dapat pengingat pajak/STNK/service kendaraan.
✓ Setelah Chat ID terdaftar di sistem:

Anda akan otomatis menerima pengingat 30 hari, 14 hari, 7 hari, 1 hari sebelum jatuh tempo, dan pada hari-H. Tidak perlu install aplikasi apapun selain Telegram.
