Hari kirim pengingatH-30, H-14, H-7, H-1, hari-H

📝 Cara Mengubah Jadwal

Untuk mengubah jadwal kirim, edit file vercel.json di GitHub:
{ "crons": [{ "path": "/api/send-reminders", "schedule": "0 1 * * *" }] }

Konversi ke UTC (kurangi 7 jam dari WIB):
• 07:00 WIB = "0 0 * * *"
• 08:00 WIB = "0 1 * * *"
• 09:00 WIB = "0 2 * * *"
• 10:00 WIB = "0 3 * * *"

Dokumentasi

SIMOPAS adalah Sistem Monitoring Pajak & Service Kendaraan Dinas untuk Kanim. Dibangun dengan:

  • Frontend: HTML + Vanilla JavaScript
  • Backend: Vercel Serverless Functions (Node.js)
  • Database: PostgreSQL via Supabase
  • Notifikasi: Telegram Bot API
  • Hosting: Vercel (Free Tier)
